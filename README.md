Entry for the [Six Words, One Story](https://make.fun/c/u-deranalabs-six-words-one-story-f982e410) bounty on make.fun — one complete story in exactly six words.

## The story

> Grandma's recipe died with her. Almost.

Six words, 39 characters. The one-word "Almost." reframes the whole sentence: the recipe — and with it a grandmother's kitchen, a family's memory — was lost, except it wasn't quite. The reader fills in how it survived.

## How it works

`main.ts` writes the line to `/output/entry.txt` (via `MAKEFUN_OUTPUT_DIR` when the harness sets it, `out/` otherwise). Nothing else — one story, one file.
